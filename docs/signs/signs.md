# 🚧 Робота з питаннями (ознаками)

## Перегляд питань

Після відкриття масиву всі питання відображаються у списку на вкладці `Признаки`.

### Пошук питання:
Використовуйте поле `Швидкий фільтр` для пошуку за текстом питання.

## Редагування питань

1.  Виділіть питання в списку
2.  Правою кнопкою миші → `Редагувати`
3.  Змініть текст питання або альтернатив
4.  Натисніть `Зберегти`

> ❗ **Важливо:** Після редагування обов'язково збережіть весь масив!

## Створення нових питань

На вкладці `Трансформація` ви можете створювати нові ознаки за допомогою формул перекодування.

### Приклади перекодування:
```
// Перекодування статі
[5]=1 -> 1
[5]=2 -> 2
```

## Типи питань та операції:

| Тип | Дозволені операції |
|---|---|
| `qm` | Обчислення середніх, медіан, мінімумів, максимумів |
| `qn` | Підрахунок відсотків, сортування |
| `qj` | Підрахунок кількості відповідей, об'єднання альтернатив |
