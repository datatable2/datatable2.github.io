# 🚧 Робота з питаннями (ознаками)

## Перегляд питань

Після відкриття масиву всі питання відображаються у списку на вкладці `Признаки`.

### Швидкий пошук ознак {#quick_search}
Використовуйте поле `Швидкий фільтр` для пошуку за текстом питання.

## Редагування питань {#edit}

1.  Виділіть питання в списку
2.  Правою кнопкою миші → `Редагувати`
3.  Змініть текст питання або альтернатив
4.  Натисніть `Зберегти`

> ❗ **Важливо:** Після редагування обов'язково збережіть весь масив!
