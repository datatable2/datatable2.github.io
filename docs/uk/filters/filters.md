# Фільтри та зважування

## Фільтри

Фільтри дозволяють обмежити аналіз лише тими анкетами, які відповідають заданій умові. Фільтр задається формулою у спеціальному синтаксисі.

### Як встановити фільтр

1. Перейдіть на вкладку **Фільтри**
2. Введіть формулу фільтра у поле `Формула фільтра`
3. Натисніть кнопку **Фільтр ON** (▶)
4. У статусній панелі з'явиться кількість відфільтрованих анкет

### Як зняти фільтр

Натисніть кнопку **Фільтр OFF** (⏹) — фільтр буде знято, всі анкети знову стануть доступними.

---

## Синтаксис формул фільтра

### Звернення до ознак (питань)

Номер ознаки вказується у квадратних дужках `[N]`, де `N` — номер ознаки або її ім'я (vName).

| Синтаксис | Опис |
|---|---|
| `[5]` | Значення ознаки №5 (підставляється PassportValue для `qn`, числове значення для `qm`) |
| `[5]=3` | Ознака №5 дорівнює альтернативі з PassportValue=3 (для `qn`) |
| `[5,3]` | Альтернатива 3 обрана у мультиваріантній ознаці №5 (для `qj`). Також працює для `qn` та `qm` |
| `[age]` | Звернення за іменем змінної (vName) замість номера |

### Оператори порівняння

| Оператор | Опис |
|---|---|
| `=` | Дорівнює |
| `<>` | Не дорівнює |
| `>` | Більше |
| `<` | Менше |
| `>=` | Більше або дорівнює |
| `<=` | Менше або дорівнює |

### Логічні оператори

| Оператор | Опис |
|---|---|
| `and` | Логічне І |
| `or` | Логічне АБО |
| `not` | Логічне НЕ |

### Спеціальні функції

| Функція | Опис |
|---|---|
| `NA(N)` | Повертає `true`, якщо ознака №N має значення "Немає відповіді" (No Answer) |
| `Caj(N)` | Повертає кількість обраних альтернатив для ознаки №N. Для `qm`/`qn`: 0 якщо NA, 1 інакше. Для `qj`: кількість обраних варіантів |
| `NF` | Повертає номер поточної анкети |
| `true` | Завжди істина (всі анкети) |
| `false` | Завжди хибність (жодної анкети) |

### Дужки

Використовуйте круглі дужки `()` для групування умов та зміни пріоритету операцій.

## Приклади фільтрів

### Прості фільтри

```
[1]=1
```
Ознака №1 дорівнює альтернативі 1 (наприклад, стать = чоловіча).

```
[3]>=18
```
Ознака №3 (наприклад, вік) більше або дорівнює 18.

```
[10,5]
```
У мультиваріантній ознаці №10 обрана альтернатива 5.

### Складені фільтри

```
[1]=1 and [3]>=18
```
Чоловіки віком від 18 років.

```
[1]=1 or [1]=2
```
Ознака №1 дорівнює 1 або 2.

```
([1]=1 or [1]=2) and [3]>=25
```
Ознака №1 дорівнює 1 або 2, І вік від 25.

```
not NA(5)
```
Тільки ті анкети, де ознака №5 має відповідь.

```
Caj(10)>=3
```
Тільки ті анкети, де у мультиваріантній ознаці №10 обрано 3 або більше варіантів.

### Фільтр за іменем змінної

```
[gender]=1 and [age]>=18
```
Те саме, що `[1]=1 and [3]>=18`, якщо vName ознаки №1 = `gender`, а ознаки №3 = `age`.

## Збережені фільтри

Фільтри можна зберігати для повторного використання:

1. Введіть формулу фільтра
2. Натисніть кнопку **Зберегти фільтр** (💾)
3. Введіть ім'я фільтра
4. Фільтр з'явиться у списку збережених фільтрів

Збережені фільтри прив'язані до масиву та зберігаються у XML-файлі налаштувань.

Для застосування збереженого фільтра — клікніть на нього у списку.

---

## Видалення відфільтрованих анкет

Ви можете фізично видалити анкети, які потрапили під фільтр:

1. Встановіть фільтр
2. Натисніть кнопку **Видалити відфільтровані анкети** (🗑)
3. Підтвердіть видалення

> ⚠️ **Увага!** Ця операція незворотна. Видалені анкети не можна відновити. Рекомендується зберегти копію масиву перед видаленням.

## Зважування (Weight)

Зважування дозволяє надати кожній анкеті індивідуальну вагу для коригування вибірки.

### Як увімкнути зважування

1. Оберіть метричну ознаку (`qm`) у випадаючому списку **Weight**
2. Програма автоматично присвоїть кожній анкеті вагу, рівну значенню обраної ознаки

> 💡 **Підказка:** Програма автоматично підсвічує ознаки, у тексті яких є слово `weight` або `вес`.

### Як вимкнути зважування

Оберіть `None` у випадаючому списку **Weight**. Усі ваги стануть рівними 1.

### Як працює зважування

- Вага береться з метричної ознаки (тип `qm`)
- Якщо у анкеті значення ознаки = NA (немає відповіді), вага = 0
- Зважування впливає на всі підрахунки: тотали, відсотки, середні тощо
- У статусній панелі відображається `Weight ON #N#` або `Weight OFF`

## Спліти (Split)

Спліти дозволяють автоматично розбити побудову таблиць по групах (наприклад, окрему таблицю для кожного міста).

### Як увімкнути спліт

1. Оберіть номінальну (`qn`) або мультиваріантну (`qj`) ознаку у випадаючому списку **Split**
2. При побудові таблиць програма автоматично створить окремі таблиці для кожної альтернативи обраної ознаки

### Як працює спліт

- Для `qn`-ознаки: створюється фільтр `[N]=alt` для кожної альтернативи
- Для `qj`-ознаки: створюється фільтр `[N,alt]` для кожної альтернативи
- Якщо одночасно встановлений фільтр, спліт комбінується з ним: `(фільтр) and (спліт)`
- У вихідному Excel-файлі перед кожною таблицею виводиться рядок з інформацією про спліт

### Як вимкнути спліт

Оберіть `None` у випадаючому списку **Split**.
