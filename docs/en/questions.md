# Working with Questions (Variables)

## Viewing Questions

After opening an array, all questions are displayed in the list on the `Signs` tab.

### Searching for a question:
Use the `Quick Filter` field to search by question text.

## Editing Questions

1.  Select a question in the list
2.  Right-click → `Edit`
3.  Change the question text or alternatives
4.  Click `Save`

> ❗ **Important:** After editing, be sure to save the entire array!

## Creating New Questions

On the `Transform` tab, you can create new variables using recoding formulas.

### Recoding examples:
```
// Recoding gender
[5]=1 -> 1
[5]=2 -> 2
```

## Question Types and Operations:

| Type | Allowed Operations |
|---|---|
| `qm` | Calculation of means, medians, minimums, maximums |
| `qn` | Percentage calculation, sorting |
| `qj` | Response count, combining alternatives |
