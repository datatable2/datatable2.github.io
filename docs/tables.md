# Побудова таблиць

## Створення крос-таблиці

1.  Перейдіть на вкладку `Таблиці`
2.  Перетягніть питання в поле `Рядки`
3.  Перетягніть питання в поле `Колонки`
4.  Натисніть кнопку `Побудувати таблицю`

## Налаштування таблиць

### Статистики які можна включити:
- ✅ Відсотки по колонках
- ✅ Відсотки по рядках
- ✅ Загальний відсоток
- ✅ Середнє значення
- ✅ Медіана
- ✅ Стандартне відхилення
- ✅ Стандартна помилка середнього
- ✅ Мінімум / Максимум
- ✅ Кількість респондентів (N)

### Додаткові налаштування:
- 🔹 Приховувати нульові комірки
- 🔹 Сортування рядків/колонок
- 🔹 Об'єднання комірок
- 🔹 Значущість різниць

## ТопБокси та БоттомБокси

ТопБокси дозволяють об'єднувати верхні альтернативи питання в одну групу (наприклад, оцінки 9+10).

### Додати ТопБокс:
1.  Виділіть питання
2.  Правою кнопкою миші → `Додати ТопБокс`
3.  Вкажіть які альтернативи об'єднати
