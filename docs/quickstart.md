# Швидкий початок

## Встановлення та запуск

DataTable2 не вимагає встановлення. Просто завантажте останню версію програми та запустіть файл `DataTable2.exe` (для Windows) або `./DataTable2` (для Linux).

## Перше відкриття FRM-масиву

1. Запустіть програму
2. В головному меню виберіть `FRM > Відкрити FRM`
3. Виберіть файл з розширенням `.frm`
4. Програма автоматично завантажить паспортний файл `.p`

> ✅ **Важливо:** FRM-масив складається з декількох файлів, імена яких повинні співпадати:
> - `.frm` — основний файл даних
> - `.p` — паспорт (опис питань та альтернатив)

Усі файли повинні знаходитись в одній папці.
