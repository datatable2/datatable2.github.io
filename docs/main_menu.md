# 🚧 Головне меню

## Відкривання FRM-масиву

1.  Меню `FRM > Відкрити FRM`
2.  Вибрати файл `.frm`
3.  Програма автоматично завантажить паспортний файл `.p`

Або просто перетягніть файл `.frm` у вікно програми.

## Збереження масиву

-   `FRM > Зберегти FRM` — зберегти зміни
-   `FRM > Зберегти FRM як...` — зберегти копію масиву

## Експорт даних

| Формат | Опис |
|---|---|
| 📊 **Excel (XLSX)** | Експорт побудованих таблиць |
| 📄 **SPSS (.sav)** | Експорт повного масиву для подальшого аналізу |
| 📃 **CSV** | Експорт даних у текстовий формат |

## Команди меню FRM

-   ✅ `Зберегти FRM`
-   ✅ `Зберегти FRM як...`
-   ✅ `Експорт в SPSS`
-   ✅ `Експорт в CSV`

# Локалізація

Програма підтримує дві мови інтерфейсу:

| Мова | Код |
|---|---|
| 🇺🇦 Українська | `uk` |
| 🇺🇸 Англійська | `en` |

### Як змінити мову

Меню **Мова** → оберіть потрібну мову.

Файли локалізації зберігаються у папці `lang/`:

- `DataTable2.uk.po` / `DataTable2.uk.mo` — українська
- `DataTable2.en.po` / `DataTable2.en.mo` — англійська
- `DataTable2.pot` — шаблон для нових перекладів

## Збереження та завантаження налаштувань

### Автоматичне збереження

Налаштування масиву (фільтр, weight, split, параметри таблиць, трансформація, стиль) автоматично зберігаються у XML-файлі поруч із FRM-масивом.

### Ручне збереження/завантаження

Меню **Налаштування**:

- **Зберегти налаштування** — зберігає поточні налаштування
- **Завантажити налаштування** — відновлює збережені налаштування

### Що зберігається

| Параметр | Опис |
|---|---|
| `Left_Signs` | Список ознак у рядках |
| `Top_Signs` | Список ознак у колонках |
| `Weight_Sign` | Ознака для зважування |
| `Filter_Formula` | Формула фільтра |
| `Split_Sign` | Ознака для спліту |
| `TabOptions` | Всі налаштування таблиць (статистики, значущість, бокси, сортування тощо) |
| `Transform` | Текст трансформації |
| `StylesName` | Ім'я обраного стилю |
| `SavedFilters` | Збережені фільтри |
| `Lang` | Мова інтерфейсу |

## Експорт в SPSS (.sav)

Програма дозволяє експортувати FRM-масив у формат SPSS `.sav` для подальшого аналізу.

### Як експортувати

1. Меню **FRM → Експорт в SPSS**
2. Оберіть кодування:
    - **UTF-8** — для сучасних версій SPSS
    - **CP1251** — для старих версій SPSS

### Що створюється при експорті

| Файл | Опис |
|---|---|
| `ім'я_масиву.sav` | Файл даних SPSS |
| `ім'я_масиву_spss11.mdg` | MDG-файл для SPSS 11 |
| `ім'я_масиву_spss12.mdg` | MDG-файл для SPSS 12+ |

### Особливості експорту

- Метричні ознаки (`qm`) → числові змінні SPSS (Measure = Scale)
- Номінальні ознаки (`qn`) → числові змінні SPSS (Measure = Nominal) з мітками значень
- Мультиваріантні ознаки (`qj`) → набір дихотомічних змінних (v5_1, v5_2, ...) + MDG-множина
- Missing value для всіх змінних = -99
- Імена змінних: `v1`, `v2`, `v3`... (для `qj`: `v5_1`, `v5_2`, ...)

> ⚠️ **Вимога:** Для експорту в SPSS потрібна бібліотека IBM SPSS I/O Modules (файли `spssio64.dll` / `libspssdio.so.1`), яка має знаходитись у папці `lib/win64/` або `lib/lin64/`.
