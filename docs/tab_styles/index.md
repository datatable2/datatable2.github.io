# 🚧 Вкладка "Стилі таблиць"

Стилі визначають зовнішній вигляд таблиць у Excel-файлі: шрифти, кольори, вирівнювання.

### Де знаходиться

Вкладка **Стилі** у головному вікні програми.

### Вбудовані стилі

Програма містить декілька готових стилів:

| Стиль | Опис |
|---|---|
| `default` | Стандартний стиль (Arial, 10pt, чорно-білий із кольоровими акцентами) |
| `black_and_white` | Чорно-білий стиль |
| `orange` | Стиль з помаранчевими акцентами |
| `red_and_blue` | Стиль з червоно-синіми акцентами |

### Елементи стилю

Кожен стиль складається з набору елементів, що відповідають частинам таблиці:

| Елемент | Опис |
|---|---|
| `info` | Інформаційний рядок (фільтр, спліт) |
| `td.basedata` | Дані бази (кількість респондентів) |
| `td.basedata_low` | Дані бази з малою базою (помітка) |
| `td.basetext` | Текст "Base" / "Total" |
| `td.corner` | Кутова комірка (перетин рядків і колонок) |
| `td.data` | Основні дані таблиці (відсотки, кількість) |
| `td.meandata` | Дані статистик (середнє, медіана тощо) |
| `td.meantext` | Текст статистик ("Mean", "Median" тощо) |
| `td.q1alt` | Альтернативи питання в рядках (Left) |
| `td.q1text` | Текст питання в рядках (Left) |
| `td.q1total` | Рядок Total для рядків |
| `td.q2alt` | Альтернативи питання в колонках (Top) |
| `td.q2text` | Текст питання в колонках (Top) |
| `td.q2total` | Колонка Total для колонок |
| `td.stat` | Статистичні рядки |
| `td.totaldata` | Дані у рядку/колонці Total |
| `td.totalstat` | Статистики у рядку/колонці Total |
| `td.signifabc` | Літерні позначення колонок (A, B, C...) |
| `td.signif` | Комірки значущості |
| `td.signif_more` | Значущо більше (підсвітка зеленим) |
| `td.signif_less` | Значущо менше (підсвітка рожевим) |

### Параметри кожного елемента

Для кожного елемента стилю можна налаштувати:

| Параметр | Значення |
|---|---|
| **FontName** | `Calibri`, `Arial`, `Tahoma`, `Verdana` |
| **FontSize** | Розмір шрифту (число) |
| **FontBold** | Жирний: `true` / `false` |
| **FontItalic** | Курсив: `true` / `false` |
| **FontColor** | Колір тексту (формат `$RRGGBB`) |
| **HorizontalAlign** | `left`, `center`, `justify`, `right` |
| **VerticalAlign** | `top`, `middle`, `bottom` |
| **BackgroundColor** | Колір фону (формат `$RRGGBB`) |
| **WordWrap** | Перенос слів: `true` / `false` |

### Створення нового стилю

1. Натисніть кнопку **Новий стиль** (➕)
2. Введіть ім'я стилю (тільки літери `a-z`, `0-9` та `_`)
3. Налаштуйте кожен елемент через подвійний клік у списку елементів

### Копіювання стилю

1. Оберіть стиль у списку
2. Натисніть кнопку **Копія стилю** (📋)
3. Введіть нове ім'я

### Видалення стилю

1. Оберіть стиль (не `default`)
2. Натисніть кнопку **Видалити стиль** (🗑)

> ⚠️ Стиль `default` видалити неможливо.

### Редагування елемента стилю

1. Оберіть елемент у списку ліворуч
2. Подвійний клік → відкриється вікно редагування
3. Змініть параметри шрифту, кольорів, вирівнювання
4. Натисніть **OK** для збереження

Праворуч від списку елементів відображається зразок таблиці з поточним стилем.

### Файли стилів

Стилі зберігаються у папці `styles/` у форматі INI:

```ini
[td.data]
FontName=arial
FontSize=10
FontBold=false
FontItalic=false
HorizontalAlign=center
VerticalAlign=middle
FontColor=$000000
BackgroundColor=$FFFFFF
WordWrap=true
```
