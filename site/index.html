DataTable2

DataTable2 — це десктопна програма для роботи з FRM-масивами (формат даних соціологічних/маркетингових досліджень). Програма написана на Free Pascal / Lazarus (Delphi-сумісний режим) і компілюється під Windows (win64) та Linux (lin64).

По суті, це інструмент для аналізу даних опитувань — аналог спрощеного SPSS для роботи з форматом даних FRM.

Що вміє програма?

  • Відкривати та зберігати FRM-масиви (бінарний формат даних опитувань)
  • Будувати крос-таблиці (двовимірні таблиці: питання × розбивка)
  • Фільтрація анкет за формулою (власна мова фільтрів)
  • Зважування даних (weight)
  • Спліти (розбивка таблиць по групах)
  • Статистики: відсотки, середні, медіана, стандартне відхилення, мін/макс, сума, Valid N
  • Значущість різниць (significance testing) між колонками, із попередньою колонкою, із колоною Тотал
  • ТопБокси / БоттомБокси (об'єднання альтернатив)
  • Трансформація — створення нових змінних з перекодуванням
  • Експорт в Excel (XLSX) — таблиці одразу формуються як Excel-файл
  • Експорт в SPSS (.sav) — для подальшого аналізу в SPSS
  • Стилі таблиць — налаштування зовнішнього вигляду
  • Локалізація — українська та англійська мови інтерфейсу
