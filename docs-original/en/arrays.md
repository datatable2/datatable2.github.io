# Working with Arrays

## Opening an FRM Array

1.  Menu `FRM > Open FRM`
2.  Select a `.frm` file
3.  The program will automatically load the passport file `.p`

Or simply drag and drop a `.frm` file into the program window.

## Saving an Array

-   `FRM > Save FRM` — save changes
-   `FRM > Save FRM as...` — save a copy of the array

## Data Export

| Format | Description |
|---|---|
| 📊 **Excel (XLSX)** | Export built tables |
| 📄 **SPSS (.sav)** | Export the full array for further analysis |
| 📃 **CSV** | Export data in text format |

## FRM Menu Commands

-   ✅ `Save FRM`
-   ✅ `Save FRM as...`
-   ✅ `Export to SPSS`
-   ✅ `Export to CSV`
