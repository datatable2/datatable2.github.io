# Quick Start

## Installation and Launch

DataTable2 does not require installation. Simply download the latest version and run `DataTable2.exe` (Windows) or `./DataTable2` (Linux).

## Opening Your First FRM Array

1. Launch the program
2. In the main menu, select `FRM > Open FRM`
3. Choose a file with the `.frm` extension
4. The program will automatically load the passport file `.p`

> ✅ **Important:** An FRM array consists of several files:
> - `.frm` — main data file
> - `.p` — passport (description of questions and alternatives)
> - `.shb`, `.sha` — additional passport files (not always present)

All files must be in the same folder.
